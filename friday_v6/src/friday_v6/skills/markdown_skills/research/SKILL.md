# Research

Write the result as `~/.friday/v6_vault/wiki/<topic>.md` — a distilled note, not a dump.

## Rules

- **Write one note per topic.** Slug the filename: lowercase, `-` for spaces.
- Structure: a one-line summary first, then sections. No fluff.
- **Link generously.** Reference existing notes with `[[name]]`; create forward links (`[[related-topic]]`) for what doesn't exist yet — the graph grows from these.
- If the topic relates to an existing note, `[[link]]` to it and add a `[[link]]` back.
- Cite the source (URL or observation) at the bottom when you have one.
- Answer the operator's actual question in your reply; the note is the artifact.

## Existing notes to check first

Read `~/.friday/v6_vault/wiki/` and grep it before writing, so you build on knowledge already captured rather than duplicating it.
