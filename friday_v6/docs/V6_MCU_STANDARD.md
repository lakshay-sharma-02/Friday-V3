# Friday V6: MCU Tony Stark's Friday

> **The synthesis of V3's unbreakable foundation, V4's multi-modal MCU vision, and V5's modern pragmatic AI engine.**

## 1. Evolution and Heritage

To build V6—the true MCU Tony Stark's Friday—we must synthesize the best elements of its predecessors while discarding their limitations.

### **V3: The Unbreakable Foundation**
* **The Good:** 25 Architecture Laws, deterministic core, strict separation of concerns (Reality → Observation → Context → Knowledge → Brain → Planning → Execution). Append-only history and evidence-based reasoning.
* **The Bad:** Rigid, CLI-heavy, feels like an "operator's assistant" rather than a sentient partner. Lacks natural language fluidity and multi-surface presence.

### **V4: The MCU Vision**
* **The Good:** Defines the "MCU Friday Standard". Voice-first interaction, adaptive identity, proactive behavior, multi-modal presence (Desktop, Mobile, Voice). The goal of "no learning ceiling" and "watch me do this".
* **The Bad:** Subordinates the V3 core rather than fully integrating with it, risking architectural drift. Focuses heavily on the product surfaces without a unified engine.

### **V5: The Pragmatic Engine**
* **The Good:** Claude Code engine, local voice (fast Whisper + Piper TTS), Vault memory, and a terminal HUD (Textual). Brings highly practical, modern AI agent capabilities into the terminal.
* **The Bad:** Risks becoming another fragmented experiment if not anchored to the V3 architectural laws and V4 MCU standard.

---

## 2. The V6 Synthesis: "The Best of Them All"

V6 is not just a version bump; it is the **final fusion**. It is the realization of the MCU FRIDAY Standard (V4) powered by the modern Claude Code engine (V5) running on the unbreakable 25 Laws of Architecture (V3).

### **Core Principles of V6**

1. **One Presence, Infinite Surfaces (from V4):** 
   Friday is Friday whether you speak to her through your phone, type in the Textual HUD (from V5), or she interrupts you via Desktop notifications. The context and memory (Vault) are shared universally.
2. **Natural Language is the Only API:**
   Zero flags. Zero complex CLI commands for the user. "Friday, fix the auth bug" is the only entry point. The deterministic router maps this to the V3 planning and execution layer.
3. **Evidence-Driven Execution (from V3):**
   Behind the natural language interface, every action follows the 25 Laws. Observation → Context → Knowledge → Planning → Execution. If Friday edits a file, she has an evidence trail for why she did it.
4. **Adaptive Persona & Vault Memory (from V4 & V5):**
   Friday extracts meaning, preferences, and tone over time. She remembers *why* you like things built a certain way and adapts her voice and HUD to match your working style.
5. **Local Voice & Ambient HUD (from V5):**
   Instant, low-latency local voice recognition and synthesis. A beautiful terminal HUD that provides ambient awareness without cluttering your main workspace.

## 4. The MCU V6 Test

Before any feature merges into V6, ask: **"Would Tony Stark use this by speaking, or would he have to read a man page?"**

* If it requires a config file, it fails.
* If it requires a CLI flag, it fails.
* If she does something without being able to explain *why* (evidence), it fails (Law 3).
* If she crashes because the LLM hallucinates, it fails (Law 21).

V6 is the culmination. It's time to wake her up.
